# UC-004-01: 배경음악 일시정지 지점 재개

- 상태: Implemented
- 마지막 갱신일: 2026-07-12

## 목적

사용자가 게임을 잠시 정지하거나 앱이 백그라운드로 전환된 뒤 다시 실행했을 때 배경음악이 처음부터 재시작되지 않고 멈췄던 지점부터 이어서 재생된다.

## 액터

- 사용자

## 사전 조건

- 게임 씬에 배경음악을 재생하는 `BackgroundMusicLoop`가 있어야 한다.
- 배경음악 클립이 정상적으로 로드되어 있어야 한다.
- 음악 설정이 켜져 있어야 배경음악이 들린다.

## 트리거

- 게임 또는 앱이 일시정지 상태가 된다.
- 일시정지 상태였던 게임 또는 앱이 다시 활성화된다.

## 기본 흐름

1. 시스템은 배경음악을 재생한다.
2. 게임 또는 앱이 일시정지되면 시스템은 현재 배경음악 재생 위치를 보존하고 재생을 멈춘다.
3. 게임 또는 앱이 다시 활성화되면 시스템은 보존한 위치부터 배경음악을 이어서 재생한다.
4. 배경음악이 클립 끝에 도달하면 기존처럼 페이드아웃 후 반복 재생한다.

## 대안 및 예외 흐름

- 1a. 배경음악 클립을 찾지 못하면 시스템은 배경음악을 재생하지 않는다.
- 2a. 배경음악이 재생 중이 아니면 시스템은 재개할 위치를 저장하지 않는다.
- 3a. 재개 시 배경음악 클립이 없으면 시스템은 재생을 재개하지 않는다.
- 3b. 저장된 음악 설정이 꺼져 있으면 시스템은 앱이 다시 활성화되어도 배경음악을 음소거 상태로 유지한다.

## 인수 조건

- [ ] 앱이 일시정지되면 배경음악의 현재 재생 위치가 보존된다.
- [ ] 앱이 다시 활성화되면 배경음악이 보존된 위치부터 이어진다.
- [ ] 일시정지와 재개 이후에도 기존 배경음악 페이드아웃 반복 동작이 유지된다.
- [ ] 명시적으로 배경음악을 정지하는 경우에는 기존처럼 재생 위치가 초기화된다.
- [ ] 음악 설정이 꺼진 상태에서는 앱 포커스가 복귀해도 배경음악이 들리지 않는다.

## 구현 메모

- `BackgroundMusicLoop`가 앱 pause/focus 변경 시 `AudioSource.Pause`와 `AudioSource.UnPause`를 사용해 재생 위치를 보존하도록 구현했다.
- 일시정지 중에는 배경음악 반복 coroutine이 클립 종료로 오인하지 않도록 pause 상태를 기다린다.
- 명시적 `Stop`은 기존처럼 coroutine을 중단하고 재생 위치를 초기화한다.
- 사용자 음악 설정과 앱 pause/focus 상태가 서로 덮어쓰지 않도록 `GameMusic` 설정을 `AudioSource.mute`로 별도 적용했다.
- 음악 OFF 상태가 재생 coroutine과 pause/focus 재개 상태를 중단하지 않으므로 포커스 복귀 후에도 음소거가 유지된다.
- Unity 프로젝트가 이미 열려 있어 batchmode 검증은 실행하지 못했고, Unity 포함 C# 컴파일러로 수정한 입력/오디오 런타임 스크립트 컴파일을 확인했다.
