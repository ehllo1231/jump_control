# UC-002-09: 디버그 커스텀 점프 실행

- 상태: Implemented
- 마지막 갱신일: 2026-06-27

## 목적

개발자 또는 테스터가 Play Mode에서 디버그 모드를 켠 상태로 원하는 점프 방향과 세기를 드래그 또는 숫자로 설정하고, 설정한 커스텀 점프를 반복 실행해 특정 구간을 빠르게 확인한다.

## 액터

- 개발자
- 테스터

## 사전 조건

- Play Mode에서 주인공을 조작할 수 있어야 한다.
- 설정에서 디버그 모드가 활성화되어 있어야 한다.
- 주인공이 지면에 있어야 한다.

## 트리거

- 개발자 또는 테스터가 주인공 옆의 `Custom Jump` 버튼을 누른다.

## 기본 흐름

1. 시스템은 디버그 모드가 활성화된 Play Mode에서 주인공 옆에 `Custom Jump` 버튼을 표시한다.
2. 사용자가 `Custom Jump` 버튼을 누른다.
3. 시스템은 잘리지 않는 크기의 커스텀 점프 설정 창을 표시한다.
4. 사용자가 드래그 패드에서 방향과 세기를 선택하거나 숫자 입력으로 값을 조정한다.
5. 시스템은 선택된 값에 맞춰 일반 점프처럼 방향 화살표와 파워 게이지를 표시한다.
6. 사용자가 설정을 적용한다.
7. 시스템은 주인공 옆에 `Cancel` 버튼을 표시하고 커스텀 점프 모드를 유지한다.
8. 사용자가 스페이스바를 누른다.
9. 시스템은 설정된 방향과 세기로 주인공을 점프시킨다.
10. 사용자가 착지 후 다시 스페이스바를 누르면 시스템은 같은 커스텀 점프를 다시 실행한다.

## 대안 및 예외 흐름

- 1a. 디버그 모드가 비활성화되어 있으면 시스템은 `Custom Jump` 버튼과 입력 창을 표시하지 않는다.
- 3a. 사용자가 입력 창에서 취소를 선택하면 시스템은 커스텀 점프 설정을 종료하고 일반 점프 입력을 다시 받는다.
- 4a. 게이지 퍼센트가 `0~100` 범위를 벗어나면 시스템은 `0~100` 범위로 제한한다.
- 4b. 드래그 패드에서 중심을 선택하면 시스템은 기본 위쪽 방향과 최소 세기로 값을 보정한다.
- 8a. 주인공이 공중에 있으면 시스템은 커스텀 점프를 실행하지 않고 착지를 기다린다.
- 8b. 사용자가 주인공 옆의 `Cancel` 버튼을 누르거나 `D` 키를 누르면 시스템은 커스텀 점프 모드를 해제하고 일반 점프 입력을 다시 받는다.
- 8c. 커스텀 점프 모드가 꺼져 있으면 디버그 모드 중에도 사용자가 일반 점프 입력을 진행할 수 있다.

## 인수 조건

- [ ] 설정에서 체크박스로 디버그 모드를 켜고 끌 수 있다.
- [ ] 디버그 모드가 켜진 Play Mode에서만 주인공 옆에 `Custom Jump` 버튼이 표시된다.
- [ ] `Custom Jump` 버튼을 누르면 내용이 잘리지 않는 설정 창이 표시된다.
- [ ] 설정 창에서 드래그 패드로 점프 방향과 세기를 선택할 수 있다.
- [ ] 숫자 입력으로 각도와 게이지 퍼센트를 조정할 수 있다.
- [ ] 선택된 각도와 게이지 퍼센트가 일반 점프의 방향 화살표와 파워 게이지로 표시된다.
- [ ] 커스텀 점프를 적용한 뒤 스페이스바를 누르면 설정값으로 계산한 점프가 실행된다.
- [ ] 커스텀 점프를 적용한 뒤 착지하고 다시 스페이스바를 누르면 같은 점프가 반복 실행된다.
- [ ] 주인공 옆의 `Cancel` 버튼 또는 `D` 키로 커스텀 점프 모드를 취소할 수 있다.
- [ ] 입력 창에서 취소하면 커스텀 점프 준비가 종료되고 일반 점프를 다시 사용할 수 있다.
- [ ] 커스텀 점프 모드가 취소되면 기존 일반 점프 흐름을 사용할 수 있다.

## 구현 메모

- `JumpTuningConfig`에 `debugModeEnabled` 체크박스를 추가하고 `Jump Tuning` 창의 `Debug Mode` 섹션에서 편집할 수 있게 했다.
- `PlayerController`는 Play Mode에서 디버그 모드가 켜져 있을 때 주인공 옆에 `Custom Jump` 버튼을 표시한다.
- `Custom Jump` 버튼은 주인공이 지면에 있고 일반 점프 준비가 진행 중이지 않은 `Idle` 상태에서 커스텀 입력 창을 연다.
- 커스텀 입력 창은 기존보다 큰 고정 크기로 표시해 하단 버튼이 잘리지 않도록 했다.
- 커스텀 입력 창은 드래그 패드와 숫자 입력을 함께 제공하며, 선택된 값을 `JumpAngleAim.ShowAngle`과 `JumpPowerGauge.ShowLockedValue`로 즉시 표시한다.
- 드래그 패드는 중심 기준 방향을 점프 각도로, 중심에서의 거리를 게이지 퍼센트로 변환한다.
- `Apply` 또는 설정 창이 열린 상태의 스페이스바 입력은 커스텀 점프 모드를 활성화한다.
- 커스텀 점프 모드가 활성화되면 착지 후 스페이스바를 누를 때마다 같은 각도와 게이지 퍼센트로 `PlayerJumpMotor`의 기존 점프 실행 경로를 사용한다.
- 커스텀 점프 모드가 활성화된 동안 주인공 옆에 `Cancel` 버튼이 표시되며, `Cancel` 버튼 또는 `D` 키 입력으로 모드를 해제한다.
- 커스텀 점프 모드가 꺼져 있으면 디버그 모드에서도 기존 일반 점프 상태 흐름을 그대로 사용한다.
- 게이지 퍼센트는 실행 및 표시 시 `0~100` 범위로 제한한다.
- Unity batchmode 컴파일은 같은 프로젝트가 이미 Unity에 열려 있어 실행하지 못했다.
- Unity 6000.3.1f1의 Bee rsp를 기반으로 임시 Roslyn 컴파일을 실행해 런타임 스크립트 컴파일을 확인했다.
- 실제 Play Mode에서 커스텀 점프 UI를 클릭/드래그하는 수동 검증은 수행하지 않았으므로 상태는 `Verified`가 아닌 `Implemented`로 유지한다.
