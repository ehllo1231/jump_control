# UC-002-10: 디버그 점프 위치 히스토리 이동

- 상태: Implemented
- 마지막 갱신일: 2026-06-26

## 목적

개발자 또는 테스터가 디버그 모드에서 어려운 구간의 점프를 반복 플레이하며 사용성을 확인할 수 있도록, 점프 직전 위치 히스토리를 뒤로 또는 앞으로 이동한다.

## 액터

- 개발자
- 테스터

## 사전 조건

- Play Mode에서 주인공을 조작할 수 있어야 한다.
- 설정에서 디버그 모드가 활성화되어 있어야 한다.

## 트리거

- 개발자 또는 테스터가 `R` 또는 `T` 키를 누른다.

## 기본 흐름

1. 시스템은 주인공이 점프를 실제 실행하기 직전의 위치를 시간순 히스토리에 저장한다.
2. 사용자가 디버그 모드에서 `R` 키를 누른다.
3. 시스템은 주인공을 현재 히스토리 커서보다 한 단계 이전 위치로 이동시킨다.
4. 시스템은 주인공의 현재 물리 속도와 점프 준비 표시를 정리한다.
5. 사용자가 디버그 모드에서 `T` 키를 누른다.
6. 시스템은 주인공을 현재 히스토리 커서보다 한 단계 이후 위치로 이동시킨다.
7. 시스템은 사용자가 선택한 위치에서 다시 점프를 시도할 수 있게 한다.

## 대안 및 예외 흐름

- 2a. 디버그 모드가 비활성화되어 있으면 시스템은 `R` 또는 `T` 키 이동을 실행하지 않는다.
- 3a. 이전 히스토리 위치가 없으면 시스템은 주인공을 이동시키지 않는다.
- 6a. 이후 히스토리 위치가 없으면 시스템은 주인공을 이동시키지 않는다.
- 7a. 과거 위치로 돌아간 뒤 새 점프를 실행하면 시스템은 현재 커서 이후의 앞으로 이동 히스토리를 버리고 새 점프 직전 위치를 이어서 저장한다.

## 인수 조건

- [ ] 디버그 모드에서 `R` 키를 누르면 점프 위치 히스토리를 한 단계 뒤로 이동한다.
- [ ] 디버그 모드에서 `R` 키를 여러 번 누르면 여러 번 전의 점프 직전 위치로 이동한다.
- [ ] 디버그 모드에서 `T` 키를 누르면 `R`로 되돌아간 히스토리를 한 단계 앞으로 이동한다.
- [ ] 일반 점프와 디버그 커스텀 점프 모두 점프 실행 직전 위치를 히스토리에 저장한다.
- [ ] 이전 또는 이후 히스토리 위치가 없을 때 `R` 또는 `T` 키를 눌러도 주인공은 제자리에 머문다.
- [ ] 히스토리 이동 후 주인공의 현재 속도와 점프 준비 표시가 정리되어 선택한 위치에서 다시 점프를 시도할 수 있다.
- [ ] 디버그 모드가 꺼져 있으면 `R`과 `T` 키 이동이 동작하지 않는다.

## 구현 메모

- `PlayerController.ExecuteJump`가 일반 점프와 디버그 커스텀 점프 실행 직전에 현재 `Rigidbody2D.position`을 점프 위치 히스토리에 저장한다.
- 디버그 모드에서 `R` 키는 히스토리 커서를 한 단계 뒤로, `T` 키는 한 단계 앞으로 이동한다.
- 첫 히스토리 이동 시 현재 위치를 히스토리 끝에 캡처해 `T` 키로 되돌아가기 전 위치까지 복구할 수 있게 한다.
- 과거 위치로 돌아간 뒤 새 점프를 실행하면 커서 이후의 앞으로 이동 히스토리를 버리고 새 시도 흐름을 이어간다.
- 히스토리 이동 시 커스텀 점프 창, 방향 표시, 파워 게이지를 닫고 `Rigidbody2D.linearVelocity`와 `angularVelocity`를 0으로 초기화한다.
- 이동 후 지면 상태에 따라 `Idle` 또는 착지 대기 상태로 전환한다.
- Unity 포함 C# 컴파일러로 런타임 스크립트 컴파일을 확인했다. 기존 직렬화 필드 관련 경고 3건이 출력됐고, 컴파일 오류는 없었다.
