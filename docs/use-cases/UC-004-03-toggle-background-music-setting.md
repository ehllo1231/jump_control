# UC-004-03: 배경음악 설정 전환

- 상태: Implemented
- 마지막 갱신일: 2026-07-12

## 목적

사용자가 게임 안의 설정 메뉴에서 배경음악을 켜거나 끄고 선택한 상태를 다음 실행에서도 유지한다.

## 액터

- 사용자

## 사전 조건

- 게임이 실행 중이어야 한다.

## 트리거

- 사용자가 게임 내 설정 메뉴를 연다.

## 기본 흐름

1. 시스템은 설정 메뉴에 현재 음악 ON/OFF 상태를 표시한다.
2. 사용자가 음악 토글을 누른다.
3. 시스템은 변경된 음악 상태를 즉시 적용한다.
4. 시스템은 변경된 상태를 저장한다.
5. 사용자가 설정 메뉴를 닫는다.

## 대안 및 예외 흐름

- 1a. 저장된 설정이 없으면 시스템은 음악 켜짐을 기본값으로 사용한다.
- 3a. 사용자가 음악을 끄면 현재 배경음악은 즉시 들리지 않지만 재생 위치는 계속 진행한다.
- 3b. 사용자가 음악을 다시 켜면 현재 재생 위치의 배경음악이 즉시 들린다.
- 3c. 배경음악 인스턴스가 아직 없으면 시스템은 설정만 저장하고 이후 생성되는 인스턴스에 적용한다.
- 5a. 음악이 꺼진 상태에서 앱 포커스가 변경되어도 시스템은 음소거 상태를 유지한다.

## 인수 조건

- [ ] 설정 메뉴가 저장된 음악 ON/OFF 상태를 표시한다.
- [ ] 음악을 끄면 현재 배경음악이 즉시 들리지 않는다.
- [ ] 음악을 켜면 현재 재생 위치의 배경음악이 즉시 들린다.
- [ ] 음악 설정 값은 `PlayerPrefs`에 저장된다.
- [ ] 게임을 다시 실행해도 저장된 음악 설정 값이 유지된다.
- [ ] 음악 OFF 상태는 앱 pause/focus 변경 후에도 유지된다.

## 구현 메모

- `GameMusic`이 `JumpTiming.Music.Enabled` 키로 설정을 저장하며 기본값은 ON이다.
- 설정 변경 이벤트를 받은 `BackgroundMusicLoop`가 전용 `AudioSource.mute`만 전환해 기존 재생 위치, 반복, 앱 pause/focus 동작을 유지한다.
- 새 설정 메뉴의 MUSIC 토글이 저장값을 표시하고 변경 값을 즉시 `GameMusic.Enabled`에 전달한다.
- Unity 6000.3.1f1 에디터에서 런타임 어셈블리 컴파일과 열린 설정 메뉴의 Play Mode 렌더링을 확인했다. 실제 Android 기기 오디오 출력은 연결된 기기가 없어 확인하지 못했다.
