# UC-002-04: 점프 파워 튜닝

- 상태: Implemented
- 마지막 갱신일: 2026-06-21

## 목적

개발자 또는 테스터가 게이지 차징 시간, 최소·최대 점프 세기, 게이지 반응 곡선을 변경한다.

## 액터

- 개발자
- 테스터

## 사전 조건

- `Jump Tuning` 창에 유효한 `PlayerController` 대상이 선택되어 있어야 한다.

## 트리거

- 사용자가 `Jump Tuning` 창의 파워 게이지 설정 값을 변경한다.

## 기본 흐름

1. 사용자가 게이지 차징 시간을 변경한다.
2. 사용자가 최소 점프 세기 또는 최대 점프 세기를 변경한다.
3. 사용자가 게이지 반응 곡선을 변경한다.
4. 시스템은 변경된 파워 설정을 진행 중이거나 다음 점프에 반영한다.

## 대안 및 예외 흐름

- 1a. 차징 시간이 `0.05초`보다 작으면 시스템은 `0.05초`로 보정한다.
- 2a. 최소 점프 세기가 최대 점프 세기보다 크면 시스템은 계산 시 두 값을 올바른 순서로 사용한다.
- 3a. 반응 곡선이 비어 있으면 시스템은 기본 선형 곡선 `0→0`, `1→1`을 사용한다.
- 3b. 반응 곡선 결과가 `0~1` 범위를 벗어나면 시스템은 `0~1`로 제한한다.

## 인수 조건

- [ ] 게이지 최소→최대 차징 시간을 변경할 수 있다.
- [ ] 최소·최대 점프 세기를 각각 변경할 수 있다.
- [ ] AnimationCurve로 정규화 게이지 반응을 변경할 수 있다.
- [ ] 변경된 파워 설정은 진행 중이거나 다음 점프에 반영된다.
- [ ] 기본 차징 시간은 `1.15초`이고 기본 점프 세기 범위는 `7~16`이다.

## 구현 메모

- `JumpTuningConfig`가 게이지 차징 시간, 최소·최대 점프 세기, 게이지 반응 곡선을 보관한다.
- `JumpPowerGauge`는 차징 중 매 프레임 설정된 차징 시간, 최소·최대 점프 세기와 반응 곡선을 읽는다.
- 점프 세기 반응 곡선은 X축 정규화 게이지 `0~1`, Y축 최소·최대 사이의 보간 비율 `0~1`을 의미한다.
- Unity 내장 Roslyn 컴파일러로 전체 런타임 및 Editor 스크립트 컴파일을 확인했다. 오류는 없고 기존 런타임 직렬화 필드 관련 경고 2건만 발생했다.
