# UC-008-01: Android 진동 피드백

- 상태: In Progress
- 마지막 갱신일: 2026-07-06

## 목적

사용자가 Android 기기에서 점프 준비, 점프 실행, 착지, 벽 충돌을 촉각 피드백으로 구분한다.

## 액터

- 사용자

## 사전 조건

- 게임이 Android 기기에서 실행 중이어야 한다.
- 진동 설정이 켜져 있어야 한다.

## 트리거

- 사용자가 점프 버튼을 누르거나, 점프를 실행하거나, Player가 착지 또는 벽 충돌을 한다.

## 기본 흐름

1. 사용자가 첫 번째 점프 입력을 누른다.
2. 시스템은 짧은 진동을 한 번 실행한다.
3. 사용자가 첫 번째 입력을 뗀 뒤 두 번째 점프 입력을 누르고 유지한다.
4. 시스템은 점프 차징 중 약한 진동을 반복한다.
5. 사용자가 두 번째 입력을 뗀다.
6. 시스템은 확정된 점프 세기에 맞는 진동을 실행한다.
7. Player가 착지한다.
8. 시스템은 착지 진동을 실행한다.
9. Player가 벽에 부딪혀 벽 반동을 받는다.
10. 시스템은 벽 충돌 진동을 실행한다.

## 대안 및 예외 흐름

- 1a. Android가 아닌 환경이면 시스템은 진동 요청을 무시하고 게임 흐름을 유지한다.
- 2a. 기기 또는 OS가 진동 세기 제어를 지원하지 않으면 시스템은 시간 기반 진동으로 대체한다.
- 3a. 점프 차징이 취소되면 시스템은 반복 진동을 중단한다.
- 5a. 진동 설정이 꺼져 있으면 시스템은 모든 진동 요청을 무시한다.
- 9a. 벽 충돌이 벽 반동 조건을 충족하지 않으면 시스템은 벽 충돌 진동을 실행하지 않는다.

## 인수 조건

- [ ] 첫 번째 점프 입력 시 짧은 진동이 한 번 발생한다.
- [ ] 두 번째 점프 입력을 유지하는 동안 약한 진동이 반복된다.
- [ ] 두 번째 점프 입력을 떼어 실제 점프가 실행되면 점프 세기에 따라 진동이 달라진다.
- [ ] 착지 시 진동이 발생한다.
- [ ] 벽 반동이 적용된 벽 충돌 시 진동이 발생한다.
- [ ] Android가 아닌 환경에서는 진동 기능 때문에 오류가 발생하지 않는다.
- [ ] 진동 설정이 꺼져 있으면 모든 진동이 발생하지 않는다.

## 구현 메모

- `Assets/Editor/AndroidLibraryNamespacePostprocessor.cs`에서 Unity가 생성한 `JumpTimingVibration.androidlib` Gradle 모듈에 Android Gradle Plugin 8.10 호환 namespace를 보정한다.
- 2026-07-06에 기존 generated Gradle 프로젝트에서 namespace 보정 후 `assembleDebug` 성공을 확인했다. 실제 Android 기기 진동 동작은 별도 확인이 필요하다.
