# UC-002-06: 코드 수정 중 튜닝 값 보존

- 상태: Implemented
- 마지막 갱신일: 2026-06-21

## 목적

코드 수정자가 사용자가 직접 바꾼 `jumpTuning` 직렬화 값을 임의로 기본값으로 되돌리지 않는다.

## 액터

- 코드 수정자
- 개발자

## 사전 조건

- 사용자가 씬 Player 또는 Player 프리팹의 튜닝 값을 직접 변경했을 수 있다.

## 트리거

- 코드 수정자가 점프 튜닝 관련 코드, 프리팹, 씬을 수정한다.

## 기본 흐름

1. 코드 수정자는 변경 전에 기존 직렬화 값을 사용자 작업으로 간주한다.
2. 코드 수정자는 필요한 코드 변경만 수행한다.
3. 코드 수정자는 사용자가 바꾼 튜닝 값을 기본값으로 되돌리지 않는다.
4. 충돌이 있으면 코드 수정자는 값을 덮어쓰기 전에 확인한다.

## 대안 및 예외 흐름

- 4a. 기능 구현상 기존 값을 변경해야만 하면 코드 수정자는 변경 이유와 영향을 명시한다.

## 인수 조건

- [ ] 코드 수정 후 사용자가 직접 변경한 `jumpTuning` 직렬화 값이 임의로 롤백되지 않는다.
- [ ] 새 기본값은 기존 저장값이 없는 경우에만 의미가 있다.

## 구현 메모

- `JumpTuningConfig`의 기본값은 코드 기본값이고, 씬 또는 프리팹에 저장된 직렬화 값이 있으면 그 값을 존중한다.
- 코드 수정자는 사용자 튜닝 값을 작업 중 임의로 되돌리지 않아야 한다.
