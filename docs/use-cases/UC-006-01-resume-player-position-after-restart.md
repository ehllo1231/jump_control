# UC-006-01: 재시작 시 플레이어 위치 복원

- 상태: Implemented
- 마지막 갱신일: 2026-06-27

## 목적

사용자가 게임을 종료한 뒤 다시 실행했을 때 주인공이 초기 위치가 아니라 종료 직전 위치에서 게임을 시작한다.

## 액터

- 사용자
- 테스터

## 사전 조건

- 게임 씬에 `PlayerController`가 있는 주인공이 있어야 한다.
- 이전 실행에서 저장된 주인공 위치가 있거나, 저장된 위치가 없는 첫 실행 상태여야 한다.

## 트리거

- 사용자가 게임 앱을 종료한다.
- 사용자가 게임 앱을 다시 실행한다.

## 기본 흐름

1. 시스템은 게임 종료 또는 앱 일시정지 시점의 주인공 위치를 저장한다.
2. 사용자가 게임을 다시 실행한다.
3. 시스템은 저장된 주인공 위치를 읽는다.
4. 시스템은 주인공을 저장된 위치로 이동시키고 물리 속도를 초기화한다.
5. 시스템은 복원된 위치의 지면 상태에 맞춰 주인공 상태를 초기화한다.

## 대안 및 예외 흐름

- 3a. 저장된 위치가 없으면 시스템은 씬에 배치된 기존 초기 위치에서 시작한다.
- 3b. 저장된 위치 값이 유효하지 않으면 시스템은 저장된 위치를 사용하지 않고 기존 초기 위치에서 시작한다.

## 인수 조건

- [ ] 게임 종료 또는 앱 일시정지 시점에 주인공 위치가 저장된다.
- [ ] 저장된 위치가 있으면 다음 실행 시 주인공이 해당 위치에서 시작한다.
- [ ] 저장된 위치로 복원할 때 주인공의 현재 물리 속도가 초기화된다.
- [ ] 저장된 위치가 없거나 유효하지 않으면 기존 씬 초기 위치에서 시작한다.

## 구현 메모

- `PlayerController`가 앱 일시정지 또는 종료 시 현재 `Rigidbody2D.position`을 `PlayerPrefs`에 저장한다.
- `PlayerController.Awake`에서 저장된 위치가 있으면 해당 위치로 `Rigidbody2D.position`을 복원하고 `linearVelocity`와 `angularVelocity`를 초기화한다.
- 저장된 위치 값이 없거나 NaN/Infinity이면 복원하지 않고 씬에 배치된 기존 초기 위치를 유지한다.
- 복원 후 `Physics2D.SyncTransforms`를 호출해 다음 지면 판정이 복원된 위치를 기준으로 동작하게 했다.
- Unity 포함 C# 컴파일러로 일반 런타임 스크립트 컴파일과 Android 심볼을 켠 런타임 스크립트 컴파일을 확인했다. 기존 직렬화 필드 관련 경고만 출력됐고 컴파일 오류는 없었다.
