# UC-003-08: 코드 수정 중 사용자 맵 구성 보존

- 상태: Implemented
- 마지막 갱신일: 2026-06-23

## 목적

코드 수정자가 사용자가 직접 구성 중인 씬의 발판 배치, 크기, 맵 구성 변경을 임의로 되돌리지 않는다.

## 액터

- 코드 수정자
- 맵 제작자
- 개발자

## 사전 조건

- 사용자가 Unity 씬에서 맵을 구성하고 있을 수 있다.

## 트리거

- 코드 수정자가 맵 제작 도구, Platform 코드, 씬 파일, 프리팹을 수정한다.

## 기본 흐름

1. 코드 수정자는 기존 씬 파일 변경을 사용자 맵 제작 작업으로 간주한다.
2. 코드 수정자는 요청된 기능에 필요한 파일만 수정한다.
3. 코드 수정자는 사용자가 배치한 발판 위치, 크기, 맵 구성을 임의로 롤백하지 않는다.
4. 같은 파일에서 충돌이 발생하면 코드 수정자는 변경 전에 확인한다.
5. 복구 씬이 확인된 경우 코드 수정자는 메인 씬의 `.meta` GUID를 유지한 채 씬 본문만 복구 대상 내용으로 교체한다.
6. 샘플 씬 재생성 도구는 기존 맵을 덮어쓰기 전에 명시적인 사용자 확인을 요구한다.
7. 사용자가 전날 만든 맵 구조물이 사라졌다고 보고하면 코드 수정자는 최신 백업 씬과 메인 씬을 비교해 더 완전한 맵 구성을 복구한다.
8. 복구 후 시스템은 샘플 씬 재생성이나 자동 로딩이 사용자의 기존 맵을 조용히 덮어쓰지 않도록 방지한다.

## 대안 및 예외 흐름

- 4a. 기능 구현상 사용자 씬 값을 변경해야만 하면 코드 수정자는 변경 이유와 영향을 명시한다.
- 6a. Play Mode이면 샘플 씬 재생성 도구는 실행되지 않고 Edit Mode에서 다시 실행하라고 안내한다.
- 7a. 복구 후보가 여러 개이면 코드 수정자는 Platform 개수, 삼각형 Platform 포함 여부, 파일 수정 시각을 비교해 복구 대상을 선택한다.
- 7b. 복구 후보가 현재 씬보다 불완전하면 코드 수정자는 메인 씬을 교체하지 않고 원인을 보고한다.

## 인수 조건

- [ ] 코드 수정 또는 도구 개선 중에도 사용자가 직접 구성한 씬의 발판 배치, 크기, 맵 구성 변경은 임의로 롤백되지 않는다.
- [ ] 충돌이 있는 경우 변경 전에 확인한다.
- [ ] 복구 씬으로 메인 씬을 복구할 때 메인 씬의 `.meta` GUID는 유지된다.
- [ ] 기존 메인 맵 씬이 있을 때 샘플 씬 재생성은 사용자 확인 없이 덮어쓰지 않는다.
- [ ] 백업 씬에 더 완전한 사용자 맵 구성이 있으면 메인 씬으로 복구할 수 있다.
- [ ] 복구 대상 백업에 포함된 삼각형 Platform은 도형, 꼭지점, 자식 시각 오브젝트와 충돌체 정보를 함께 유지한다.
- [ ] 샘플 씬 자동 생성/자동 열기 동작은 사용자의 기존 맵 구성을 조용히 대체하지 않는다.

## 구현 메모

- 사용자가 맵 제작 과정에서 직접 변경한 씬 파일, 발판 위치, 발판 크기, 맵 구성 값은 사용자 작업으로 간주한다.
- 코드 수정자는 관련 없는 씬 변경을 되돌리지 않는다.
- 2026-06-22에 `Assets/_Recovery/0 (1).unity`의 34개 Platform과 Player 위치 변경을 `Assets/Scenes/MVPJumpScene.unity`로 복구했다.
- 복구 시 `Assets/Scenes/MVPJumpScene.unity.meta`는 변경하지 않아 기존 씬 GUID를 유지했다.
- `MVPSceneBuilder.BuildMVPScene`은 Play Mode에서 실행되지 않으며, 기존 `Assets/Scenes/MVPJumpScene.unity`가 있으면 덮어쓰기 확인을 요구한다.
- 2026-06-23 사용자가 전날 만든 삼각형 구조물이 실행 후 사라졌다고 보고해 최신 `_Recovery` 씬을 기준으로 복구 및 재발방지를 진행한다.
- 2026-06-23 `Assets/_Recovery/0 (2).unity`에서 Platform 11개와 삼각형 Platform 1개를 확인하고 `Assets/Scenes/MVPJumpScene.unity` 본문을 해당 백업으로 복구했다. `.meta` 파일은 변경하지 않았다.
- 2026-06-23 `MapSceneBackupUtility`를 추가해 Play Mode 진입 직전 더티 맵 씬을 `Assets/_Recovery/MapSceneBackups`에 사본으로 저장하게 했다.
- 2026-06-23 `MVPSceneBuilder.BuildMVPScene`이 배치 모드에서 기존 `Assets/Scenes/MVPJumpScene.unity`를 조용히 덮어쓰지 못하도록 막았다. 명시 인자 `-jumpTimingAllowSceneOverwrite`가 있을 때만 허용한다.
- 2026-06-23 `Build MVP Scene` 배치 실행 시 기존 씬 해시가 유지되고 덮어쓰기가 건너뛰어지는 것을 확인했다.
