# UC-001: 사용자 점프

- 상태: Implemented
- 마지막 갱신일: 2026-06-21

## 목적

사용자가 첫 번째 점프 버튼 입력으로 방향 표시를 시작하고, 두 번째 입력으로 방향을 확정한 뒤 버튼을 누르고 있는 시간 동안 점프 힘을 조절하여 주인공을 점프시킨다.

## 액터

- 사용자

## 사전 조건

- 주인공이 지면에 있어야 한다.
- 점프 준비 또는 점프 동작이 이미 진행 중이지 않아야 한다.

## 트리거

- 지면에 있는 주인공을 조작하는 사용자가 점프 버튼을 처음 누른다.

## 기본 흐름

1. 사용자가 점프 버튼을 처음 누른다.
2. 시스템은 Unity Inspector에 설정된 각도 범위와 속도로 점프 방향을 왕복 표시한다. 기본 범위는 `-62°~62°`다.
3. 사용자가 처음 눌렀던 점프 버튼을 뗀 다음, 점프 버튼을 두 번째로 누르고 누른 상태를 유지한다.
4. 시스템은 두 번째 버튼을 누른 순간 표시 중인 방향을 확정하고, Inspector에 설정된 차징 시간으로 왕복하는 점프 게이지를 표시한다.
5. 사용자가 두 번째로 눌렀던 점프 버튼을 뗀다.
6. 시스템은 버튼을 뗀 순간의 점프 게이지를 확정하고, 설정된 최소·최대 점프 세기와 반응 곡선으로 힘을 계산하여 확정한 방향으로 주인공을 점프시킨다. 기본 점프 세기 범위는 `7~16`이다.

## 대안 및 예외 흐름

- 1a. 주인공이 공중에 있으면 시스템은 첫 번째 점프 입력을 받지 않는다.
- 1b. 주인공의 발 콜라이더 일부만 발판 끝에 닿아 있어도 시스템은 지면 접촉으로 판정하고 첫 번째 점프 입력을 받는다.
- 2a. 기본 흐름 2~5를 진행하는 동안 주인공이 지면을 벗어나면 시스템은 점프 준비를 취소하고 착지를 기다린다.
- 3a. 사용자가 첫 번째 버튼을 뗀 뒤 두 번째로 누르지 않으면 방향은 설정된 속도로 계속 왕복하며, 취소 또는 시간 제한을 둘지는 TBD다.
- 5a. 사용자가 두 번째 버튼을 계속 누르고 떼지 않으면 점프 게이지는 설정된 차징 시간에 따라 계속 왕복한다.

## 인수 조건

- [ ] 첫 번째 점프 버튼을 누르기 전에는 점프 방향과 게이지를 표시하지 않는다.
- [ ] 지면에서 첫 번째 점프 버튼을 누르면 Inspector에 설정된 범위와 속도로 왕복하는 점프 방향이 표시된다.
- [ ] 첫 번째 점프 버튼을 떼기 전에는 두 번째 입력을 받지 않는다.
- [ ] 첫 번째 버튼을 뗀 다음 두 번째 점프 버튼을 누르면 표시 중인 방향이 확정되고 더 이상 움직이지 않는다.
- [ ] 방향을 확정한 순간 Inspector에 설정된 차징 시간으로 왕복하는 점프 게이지가 표시된다.
- [ ] 두 번째 점프 버튼을 누르고 있는 동안에는 주인공이 점프하지 않는다.
- [ ] 두 번째 점프 버튼을 떼는 순간 표시 중인 점프 게이지가 확정된다.
- [ ] 시스템은 두 번째 입력에서 확정한 방향과 최소·최대 점프 세기 및 반응 곡선으로 계산한 힘을 사용하여 주인공을 점프시킨다.
- [ ] 공중에서 발생한 점프 입력은 점프 준비를 시작하지 않는다.
- [ ] 주인공이 발판 끝에 걸려 발 콜라이더 일부만 지면에 닿은 상태에서도 다음 점프 입력을 시작할 수 있다.

## 구현 메모

- `PlayerController`의 상태 흐름을 `첫 입력 대기 → 방향 표시 → 첫 버튼 해제 대기 → 두 번째 누름에서 방향 확정 및 게이지 시작 → 점프` 순서로 변경했다.
- 대기 상태에서는 방향과 게이지를 숨기고, 첫 번째 버튼을 누른 순간 방향 표시를 시작한다.
- 첫 번째 버튼 해제 이벤트를 받은 후에만 두 번째 누름을 받을 수 있다.
- 두 번째 버튼을 누른 순간 현재 방향을 저장하고 방향 갱신을 중단한 뒤 게이지를 시작한다.
- 두 번째 버튼을 뗀 순간 현재 파워를 저장하고, 확정한 방향과 파워로 점프한다.
- 준비 과정의 모든 단계에서 지면 상태를 검사하며, 지면을 벗어나면 준비를 취소하고 착지를 기다린다.
- `PlayerController > Jump Tuning`에서 방향 범위·속도, 게이지 차징 시간, 최소·최대 점프 세기와 게이지 반응 곡선을 설정하도록 변경했다.
- 기본 방향 범위 `-62°~62°`, 기본 방향 속도 `145°/초`, 기본 차징 시간 `1.15초`, 기본 점프 세기 `7~16`을 유지한다.
- 기존 지면 판정은 발 중앙의 반지름 `0.08` 원만 검사하여 발판 끝 접촉을 놓칠 수 있었다.
- `GroundChecker`를 플레이어 콜라이더의 발 전체 폭과 높이 `0.16` 영역을 검사하는 박스 판정으로 변경했다.
- 후보 지면의 윗면이 플레이어 발 높이와 가까운지도 확인하여 발판 측면 접촉이 지면으로 판정되는 것을 제한했다.
- 주인공 크기를 변경해도 `GroundChecker`가 현재 BoxCollider2D의 실제 하단과 폭을 사용하도록 갱신했다.
- Unity 내장 Roslyn 컴파일러로 전체 런타임 스크립트 컴파일을 확인했다. 오류는 없고 기존 직렬화 필드 관련 경고 2건만 발생했다.
- Play Mode 직접 실행 검증은 수행하지 않았으므로 상태는 `Verified`가 아닌 `Implemented`로 유지한다.
