# UC-009-01: 게임 내 설정 메뉴 열기

- 상태: Implemented
- 마지막 갱신일: 2026-07-12

## 목적

사용자가 게임 플레이를 불필요하게 가리지 않는 우측 상단 톱니바퀴 버튼으로 설정 메뉴를 열고 닫는다.

## 액터

- 사용자

## 사전 조건

- 게임이 실행 중이어야 한다.

## 트리거

- 사용자가 게임 화면 우측 상단의 톱니바퀴 버튼을 누른다.

## 기본 흐름

1. 시스템은 닫힌 상태에서 화면 우측 상단 안전 영역 안에 톱니바퀴 버튼만 표시한다.
2. 사용자가 톱니바퀴 버튼을 누른다.
3. 시스템은 진동 및 음악 설정이 포함된 새 설정 메뉴를 표시한다.
4. 사용자가 메뉴의 닫기 버튼 또는 톱니바퀴 버튼을 누른다.
5. 시스템은 설정 메뉴를 닫고 톱니바퀴 버튼만 남긴다.

## 대안 및 예외 흐름

- 1a. 화면 크기나 안전 영역이 바뀌면 시스템은 버튼과 메뉴 크기 및 위치를 다시 계산한다.
- 2a. 설정 UI에서 시작된 입력은 시스템이 점프 입력으로 전달하지 않는다.
- 4a. 사용자가 열린 메뉴 바깥 영역이나 Escape 키를 누르면 시스템은 메뉴를 닫는다.

## 인수 조건

- [ ] 게임 도중 우측 상단 안전 영역 안에 톱니바퀴 모양 설정 버튼이 표시된다.
- [ ] 메뉴가 닫혀 있을 때 설정 버튼 외의 설정 UI는 게임 화면을 가리지 않는다.
- [ ] 기존 `Settings` 텍스트 버튼과 드래그 가능한 기본 창은 표시되지 않는다.
- [ ] 톱니바퀴 버튼으로 진동 및 음악 설정 메뉴를 열고 닫을 수 있다.
- [ ] 메뉴는 화면 크기 및 Android 안전 영역 안에 배치된다.
- [ ] 설정 버튼과 열린 메뉴에서 발생한 입력은 점프 입력으로 처리되지 않는다.

## 구현 메모

- 기존 `GUI.Window` 기반 텍스트 설정창을 제거하고, 런타임 생성 톱니 아이콘 버튼과 고정형 설정 패널로 교체했다.
- `Screen.safeArea`, 화면 해상도, DPI를 기준으로 버튼과 패널 크기 및 위치를 매 프레임 계산한다.
- 메뉴가 열리면 배경을 낮은 명도로 처리하고 VIBRATION 및 MUSIC ON/OFF 토글과 닫기 아이콘만 표시한다.
- 열린 메뉴는 전체 터치 입력을 차단하며 설정 버튼에서 시작된 포인터도 해제될 때까지 점프 입력으로 전환되지 않는다.
- Unity 6000.3.1f1 Play Mode에서 닫힌 버튼과 열린 메뉴의 위치, 텍스트, 토글 겹침이 없는 것을 직접 확인했다. Android 노치 기기의 실제 안전 영역은 연결된 기기가 없어 확인하지 못했다.
