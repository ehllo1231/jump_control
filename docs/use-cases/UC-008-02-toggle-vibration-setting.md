# UC-008-02: 진동 설정 전환

- 상태: Implemented
- 마지막 갱신일: 2026-07-12

## 목적

사용자가 게임 안의 설정 메뉴에서 Android 진동 피드백을 켜거나 끈다.

## 액터

- 사용자

## 사전 조건

- 게임이 실행 중이어야 한다.

## 트리거

- 사용자가 게임 화면 우측 상단의 톱니바퀴 버튼을 누른다.

## 기본 흐름

1. 사용자가 게임 화면 우측 상단의 톱니바퀴 버튼을 누른다.
2. 시스템은 설정 메뉴와 현재 진동 ON/OFF 상태를 표시한다.
3. 사용자가 진동 토글을 누른다.
4. 시스템은 변경된 상태를 즉시 적용하고 저장한다.
5. 시스템은 이후 진동 요청에 저장된 설정을 적용한다.
6. 사용자가 설정 메뉴를 닫는다.

## 대안 및 예외 흐름

- 1a. 사용자가 톱니바퀴 버튼 또는 열린 설정 메뉴를 터치하면 시스템은 해당 터치를 점프 입력으로 처리하지 않는다.
- 3a. 진동 설정을 끄는 순간 진행 중인 진동이 있으면 시스템은 진동을 중단한다.
- 4a. 저장된 설정이 없으면 시스템은 진동 켜짐을 기본값으로 사용한다.

## 인수 조건

- [ ] 새 설정 메뉴가 저장된 진동 ON/OFF 상태를 표시한다.
- [ ] 설정 메뉴에서 진동을 켜거나 끄면 즉시 적용된다.
- [ ] 진동 설정 값은 `PlayerPrefs`에 저장된다.
- [ ] 게임을 다시 실행해도 저장된 진동 설정 값이 유지된다.
- [ ] 진동 설정이 꺼져 있으면 점프, 차징, 착지, 벽 충돌 진동이 발생하지 않는다.
- [ ] 설정 메뉴 터치는 점프 입력으로 처리되지 않는다.

## 구현 메모

- 새 설정 메뉴의 VIBRATION 토글이 `GameHaptics.Enabled` 저장값을 표시하고 변경 값을 즉시 적용한다.
- 진동을 끄면 `GameHaptics`가 차징 피드백과 진행 중인 Android 진동을 중단하고 이후 진동 요청을 무시한다.
- 메뉴가 열려 있거나 설정 버튼에서 시작된 포인터가 해제되지 않은 동안 `JumpInputReader`로 전달되는 터치 입력을 차단한다.
- Unity 6000.3.1f1 에디터에서 컴파일과 설정 메뉴 렌더링을 확인했다. Android 실기기 진동은 연결된 기기가 없어 확인하지 못했다.
