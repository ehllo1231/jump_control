# UC-007-03: 플레이테스트 로그 뷰어 툴

- 상태: Implemented
- 마지막 갱신일: 2026-06-27

## 목적

개발자가 Unity Scene View 오버레이가 아니라 별도 툴 창에서 현재 게임 맵과 여러 플레이테스트 로그 궤적을 함께 확인한다.

## 액터

- 개발자
- 맵 제작자
- 테스터

## 사전 조건

- Unity Editor에서 게임 맵 씬이 열려 있어야 한다.
- 현재 씬의 맵 오브젝트에는 2D Collider가 있어야 한다.
- 플레이테스트 로그 파일이 하나 이상 존재할 수 있다.

## 트리거

- 사용자가 `Tools/Jump Timing/Log Viewer` 메뉴를 연다.

## 기본 흐름

1. 시스템은 현재 열린 Unity 씬의 2D Collider를 읽어 툴 창의 맵 화면에 표시한다.
2. 시스템은 맵 화면을 확대 및 축소할 수 있게 한다.
3. 시스템은 맵 화면을 드래그해서 표시 위치를 이동할 수 있게 한다.
4. 시스템은 저장된 플레이테스트 로그 목록을 오른쪽 패널에 표시한다.
5. 사용자는 표시할 로그를 체크한다.
6. 사용자는 맵 화면에 점프 마커와 착륙 마커를 표시할지 각각 선택한다.
7. 시스템은 체크된 로그의 이동 궤적, 켜져 있는 점프 지점/착륙 지점, 낙하 지점을 맵 화면 위에 표시한다.
8. 사용자가 여러 로그를 체크하면 시스템은 여러 로그를 같은 맵 화면에 겹쳐 표시한다.

## 대안 및 예외 흐름

- 1a. 현재 씬에 표시할 2D Collider가 없으면 시스템은 빈 맵 화면을 표시한다.
- 4a. 로그 파일이 없으면 시스템은 로그 목록을 비워 둔다.
- 6a. 점프 마커 또는 착륙 마커 표시가 꺼져 있으면 시스템은 해당 마커만 그리지 않고 이동 궤적과 다른 마커 표시는 유지한다.
- 7a. 체크한 로그 파일을 읽지 못하면 시스템은 해당 로그의 오류를 목록에 표시하고 다른 로그 표시는 유지한다.

## 인수 조건

- [ ] 현재 Unity 씬의 맵이 툴 창의 맵 화면에 표시된다.
- [ ] 맵 화면을 확대 및 축소할 수 있다.
- [ ] 맵 화면을 드래그해서 표시 위치를 이동할 수 있다.
- [ ] 오른쪽 패널에서 로그 목록을 확인할 수 있다.
- [ ] 체크한 로그의 궤적이 맵 화면 위에 표시된다.
- [ ] 로그에 기록된 궤적 끊김 지점에서는 맵 화면 이동 궤적 선이 이어지지 않는다.
- [ ] 체크한 로그의 점프 지점, 착륙 지점, 낙하 지점이 구분되는 마커로 표시된다.
- [ ] Log Viewer에서 점프 마커 표시를 켜고 끌 수 있다.
- [ ] Log Viewer에서 착륙 마커 표시를 켜고 끌 수 있다.
- [ ] 여러 로그를 체크하면 여러 궤적이 같은 맵 화면에 겹쳐 표시된다.

## 구현 메모

- `Tools/Jump Timing/Log Viewer` Editor 창을 추가했다.
- 왼쪽 맵 화면은 현재 활성 Unity 씬의 2D Collider를 월드 좌표 기준으로 읽어 그린다.
- 사각형, 다각형, Composite, Circle, Edge Collider를 맵 화면에 표시한다.
- Player 자신의 Collider는 맵 지형에서 제외하고, 현재 씬의 Player 위치는 별도 마커로 표시한다.
- 마우스 휠과 툴바 버튼으로 확대/축소할 수 있고, 왼쪽 드래그 또는 가운데 마우스 드래그로 맵 화면을 이동할 수 있다.
- 오른쪽 로그 목록에서 여러 로그를 체크하면 각 로그의 이동 궤적, 점프 지점, 착륙 지점, 낙하 지점이 같은 맵 화면 위에 겹쳐 표시된다.
- 오른쪽 패널에서 점프 마커와 착륙 마커 표시 여부를 각각 켜고 끌 수 있으며, 설정은 EditorPrefs에 저장된다.
- 로그에 `path_break` 레코드가 있으면 해당 지점의 이전 샘플과 다음 샘플 사이에는 이동 궤적 선을 그리지 않는다.
- Unity Roslyn 응답 파일 기반으로 런타임 및 Editor 스크립트 컴파일을 확인했다.
- 실제 Unity Editor 창에서 확대/축소, 드래그 이동, 착륙 마커, 궤적 끊김 및 복수 로그 표시를 수동 조작하는 검증은 수행하지 않았으므로 상태는 `Verified`가 아닌 `Implemented`로 유지한다.
