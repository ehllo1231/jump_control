# UC-002-03: 점프 방향 튜닝

- 상태: Implemented
- 마지막 갱신일: 2026-07-17

## 목적

개발자 또는 테스터가 점프 방향의 최소 각도, 최대 각도, 왕복 속도, 시작 위치, 화살표 표시 위치를 변경한다.

## 액터

- 개발자
- 테스터

## 사전 조건

- `Jump Tuning` 창에 유효한 `PlayerController` 대상이 선택되어 있어야 한다.

## 트리거

- 사용자가 `Jump Tuning` 창의 방향 설정 값을 변경한다.

## 기본 흐름

1. 사용자가 최소 각도 또는 최대 각도를 변경한다.
2. 사용자가 방향 왕복 속도를 변경한다.
3. 사용자가 방향 시작 위치를 변경한다.
4. 사용자가 주인공이 오른쪽을 볼 때와 왼쪽을 볼 때의 화살표 X 오프셋을 각각 입력한다.
5. 사용자가 양쪽 방향에 공통으로 적용할 화살표 Y 오프셋을 입력한다.
6. 시스템은 주인공의 현재 바라보기 방향에 맞는 X 오프셋과 공통 Y 오프셋을 진행 중이거나 다음 방향 조준에 반영한다.

## 대안 및 예외 흐름

- 1a. 최소 각도가 최대 각도보다 크면 시스템은 계산 시 두 값을 올바른 순서로 사용한다.
- 2a. 방향 왕복 속도가 `0`보다 작으면 시스템은 `0`으로 보정한다.
- 3a. 시작 위치가 `0~1` 범위를 벗어나면 시스템은 `0~1`로 제한한다.
- 4a. 방향별 화살표 X 오프셋에 유한하지 않은 값이 들어오면 시스템은 해당 방향의 기본 X 위치로 보정한다.
- 5a. 화살표 Y 오프셋에 유한하지 않은 값이 들어오면 시스템은 기본 Y 위치로 보정한다.
- 6a. 기존 단일 `Arrow X Offset`만 저장되어 있으면 시스템은 그 값을 오른쪽·왼쪽 설정에 모두 승계해 기존 표시 위치를 유지한다.

## 인수 조건

- [ ] 최소·최대 방향 각도를 `Jump Tuning` 창에서 변경할 수 있다.
- [ ] 방향 왕복 속도를 `Jump Tuning` 창에서 변경할 수 있다.
- [ ] 방향 시작 위치를 `Jump Tuning` 창에서 변경할 수 있다.
- [x] 오른쪽을 볼 때와 왼쪽을 볼 때의 화살표 X 오프셋을 `Jump Tuning` 창에서 각각 입력할 수 있다.
- [x] 양쪽 방향에 공통으로 적용되는 화살표 Y 오프셋을 `Jump Tuning` 창에서 입력할 수 있다.
- [x] 주인공의 현재 바라보기 방향이 바뀌면 화살표가 해당 방향의 X 오프셋을 사용한다.
- [x] 기존 단일 Arrow X 오프셋은 방향별 설정으로 마이그레이션한 뒤에도 양쪽 방향에서 같은 위치를 유지한다.
- [ ] 변경된 방향 설정과 화살표 표시 위치는 진행 중이거나 다음 방향 조준에 반영된다.
- [ ] 기본 방향 범위는 `-62°~62°`이고 기본 방향 속도는 `145°/초`다.
- [ ] 기본 화살표 표시 위치는 기존과 같은 로컬 오프셋 `X=0`, `Y=0.86`이다.

## 구현 메모

- `JumpTuningConfig`가 방향 최소·최대 각도, 왕복 속도, 시작 위치를 보관한다.
- `JumpAngleAim`은 조준 중 매 프레임 설정된 최소·최대 각도와 방향 속도를 읽으므로 Play Mode 변경값이 즉시 반영된다.
- Unity 내장 Roslyn 컴파일러로 전체 런타임 및 Editor 스크립트 컴파일을 확인했다. 오류는 없고 기존 런타임 직렬화 필드 관련 경고 2건만 발생했다.
- 2026-07-05 `JumpTuningConfig`에 화살표 표시 위치 X/Y 오프셋을 추가하고 `JumpAngleAim` 표시 위치와 `Jump Tuning` 창의 Direction 섹션에 연결했다.
- 2026-07-05 Unity 내장 Roslyn 컴파일러로 런타임 및 Editor 스크립트 컴파일을 확인했다.
- 2026-07-17 `JumpTuningConfig`의 Arrow X 오프셋을 오른쪽/왼쪽 바라보기 값으로 분리하고 `Jump Tuning` 창에 두 입력 필드를 추가했다.
- 기존 `aimArrowXOffset`은 `FormerlySerializedAs`로 오른쪽 값에 승계하고, 최초 검증 시 왼쪽 값에도 복사해 기존 양방향 표시 위치를 유지한다.
- `PlayerVisual.IsFacingLeft`와 `JumpAngleAim`을 연결해 조준 각도가 아닌 주인공의 실제 바라보기 상태로 X 오프셋을 선택한다.
- Unity Editor 직접 실행 검증에서 오른쪽 X `0.42`, 왼쪽 X `-0.73`, 공통 Y `1.1` 적용과 기존 단일 X `0.25`의 양방향 마이그레이션을 확인했다.
- Unity 내장 Roslyn 컴파일러로 런타임 및 Editor 스크립트 컴파일을 확인했다.
